# Evgeny Lashkov Landing

SEO-oriented public facts landing page for Evgeny Igorevich Lashkov.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Environment

Set `NEXT_PUBLIC_SITE_URL` to the production URL for canonical metadata, sitemap, robots.txt, and JSON-LD.

Default production URL:

```bash
NEXT_PUBLIC_SITE_URL=https://evgenylashkov.vercel.app
```
